# AI Marketing Agent — WhatsApp → Meta Ads + TikTok Ads

أتمتة n8n كاملة: ترسل رسالة نصية من واتساب، والذكاء الاصطناعي (Claude) يفهم طلبك ويدير حملاتك
الإعلانية فعلياً على **Facebook/Instagram (Meta Ads)** و **TikTok Ads** — إنشاء حملة، تفعيل، إيقاف،
تعديل ميزانية، حذف، أو تقرير — كل هذا من محادثة واتساب عادية، بدون ما تفتح مدير الإعلانات يدوياً.

## الفكرة بسرعة

```
رسالة واتساب  →  Claude يفهم الطلب  →  تحقق من الصلاحية والبيانات  →  Meta Ads / TikTok Ads API
                                                                              ↓
                                                        رد بواتساب + تسجيل بجوجل شيتس
```

هذا يطابق نموذج "المساعد/المدير الرقمي": صاحب العمل ما يحتاج يدخل لكل منصة يدوياً — يرسل طلبه بواتساب
والنظام ينفذ وياخذ باقي التفاصيل ويرجع له بالنتيجة والتقرير.

## شنو تسويه الأتمتة

1. تستلم رسالة واتساب وتتأكد إن رقم المرسل مصرح له (من شيت جوجل، مو مكتوب بالكود).
2. ترسل نص الرسالة لـ Claude ليحوّلها لأمر منظم: نوع العملية، المنصة، اسم الحملة، الميزانية...إلخ.
3. إذا ناقصة معلومات، ترد وتسأل عنها وتحفظ حالة المحادثة حتى تكمل بالرسالة الجاية.
4. إذا العملية خطرة (تفعيل حملة فعلية أو حذف)، تطلب تأكيد صريح قبل التنفيذ.
5. تتحقق من ربط رقم المرسل بحساب إعلاني حقيقي (شيت "العملاء") بدون تسريب بيانات عملاء ثانين.
6. تنفذ الطلب فعلياً عبر Meta Graph API و/أو TikTok Business API.
7. تسجل كل عملية (نجحت أو فشلت) بجوجل شيتس، وترد على واتساب بالنتيجة.
