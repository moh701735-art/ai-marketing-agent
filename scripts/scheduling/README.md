## Audience rotation on cost cap (Meta)
- Shared engine workflow `7NWaY0zGwHw8lBFH` (`rot_core.js`, SDK source `rot.sdk.ts`, tests `test_rot.cjs`).
- Per-bot patch generated by `gen_rot.py <live_workflow.json> <ops.json>`: patches `سقف ميتا: تجهيز/قرار`, `سقف الرسالة: تجهيز/حفظ` and adds 17 `تدوير:` nodes after `سقف ميتا: إيقاف الحملة`.
- Cap tables need a string column `rot` (JSON: on, gen, max, root, used[], acct). Enable per campaign from Telegram: "سقف الرسالة 30 سنت وبدل الجمهور".
- Flow: cost per message >= cap -> pause -> copy campaign (deep copy, inherits status) -> set age bracket (25-34, 35-44, 18-24, 45-65, first not used) + advantage_audience 0 on every ad set -> activate -> register new row (gen+1, max 3) -> Telegram notice.
