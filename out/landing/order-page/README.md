# صفحة طلب (Order page) مع بكسل سناب

صفحة واحدة ثابتة (بدون بناء). غيّر قسم `SHOP` فقط داخل `index.html` (الاسم، السعر، المميزات، الصور، رقم واتساب).

- بكسل سناب: `bee15341-7ae6-477f-ae0f-b0f0db91347c` (بدون user_email).
- أحداث حقيقية فقط: `PAGE_VIEW` (فتح الصفحة)، `VIEW_CONTENT`، `START_CHECKOUT` (أول لمس للنموذج)، `PURCHASE` (إرسال الطلب بعد التحقق من الحقول، الدفع عند الاستلام). لا أحداث وهمية.
- الطلب يُرسل لرقم الواتساب برسالة جاهزة. لا يُخزَّن شي بسيرفر.
- النشر: Netlify (مجلد `out/landing/order-page`).
