# دليل التنصيب خطوة بخطوة — AI Marketing Agent (WhatsApp)

هذا الدليل يوصّلك من صفر لين الأتمتة تشتغل: رسالة واتساب تدير حملات إعلانية على Meta وTikTok.

## شنو تسوي الأتمتة بالضبط؟

عميل أو أنت ترسل رسالة نصية بواتساب (مثلاً: "سوي حملة فيسبوك اسمها تخفيضات الصيف بميزانية 20 دولار")،
والأتمتة:
1. تتأكد إن رقمك مصرح له.
2. تفهم طلبك بواسطة Claude وتحوّله لأمر منظم (إنشاء / تفعيل / إيقاف / تعديل ميزانية / حذف / تقرير).
3. إذا ناقصة تفاصيل، ترد وتسألك عنها.
4. إذا العملية خطرة (تفعيل أو حذف)، تطلب منك تأكيد صريح بكلمة "تأكيد".
5. تنفذ الطلب فعلياً على Meta Ads و/أو TikTok Ads حسب المنصة اللي ذكرتها.
6. تسجل النتيجة بجداول بيانات n8n الداخلية (Data Tables) وترد عليك بواتساب بالنتيجة.

⚠️ هذي الأتمتة **تدير حملات إعلانية مدفوعة (Ads)** — مو نشر منشورات عادية. أي "إنشاء حملة" أو "تعديل
ميزانية" فعلي معناها صرف فلوس حقيقية على المنصة. جرّب دايماً بحملة تجريبية بميزانية صغيرة أول.

📌 **التخزين:** الأتمتة تستخدم **Data Tables** المدمجة بـ n8n (مو Google Sheets) — يعني ما تحتاج أي
ربط أو صلاحيات Google إطلاقاً لهذا الجزء. أبسط وأسرع وأكثر أماناً.

---

## المتطلبات قبل ما تبدأ

- حساب n8n Cloud (أو نسخة self-hosted حديثة) تدعم ميزة **Data Tables** وSwitch node v3.
- حساب WhatsApp Business Cloud API (عبر Meta for Developers).
- Business Manager بميتا فيه صلاحية إعلانات (Meta Ads).
- حساب TikTok for Business Developer (لواجهة TikTok Business API).
- مفتاح Anthropic API (لتشغيل Claude).

## الخطوة 1 — استيراد الأتمتة لـ n8n

1. افتح n8n.
2. اضغط **Workflows** من القائمة الجانبية → **Import from File**.
3. اختار ملف `workflows/ai-marketing-agent-whatsapp.json` من هذا الريبو.

---

## الخطوة 2 — جهّز 4 جداول بيانات (Data Tables)

1. بـ n8n اضغط **Overview** → تبويب **Data tables** → **Create data table**.
2. سوّي 4 جداول **بهذي الأسماء بالضبط** (انسخها بدل ما تكتبها يدوياً لتفادي أي غلطة إملائية):

### جدول 1: `المستخدمين المصرح لهم`
أعمدة: `phone`, `name`, `active`

أضف صف فيه رقمك:
| phone | name | active |
|-------|------|--------|
| 9647811317191 | صاحب العمل | |

- `phone`: أي صيغة (بـ +964 أو 0 أو 964) — الأتمتة تطبّعها تلقائياً.
- `active`: خلّيه فاضي للتفعيل، واكتب `false` لتعطيل رقم مؤقتاً بدون حذف صفه.

### جدول 2: `الحالة المعلقة`
أعمدة: `phone`, `draft_json`

خليه فاضي (بدون صفوف) — الأتمتة تعبيه وتصفّره لحالها.

### جدول 3: `العملاء`
أعمدة: `client`, `meta_ad_account_id`, `tiktok_advertiser_id`, `phone`

أضف صف لكل عميل (أو لنفسك للتجربة):
| client | meta_ad_account_id | tiktok_advertiser_id | phone |
|--------|--------------------|-----------------------|-------|
| اسم عميلك | 123456789012345 (بدون act_) | 7601994762471637008 | 9647811317191 |

هذا الجدول هو اللي يربط رقم واتساب بحساب العميل الإعلاني. كل عميل (أو كل رقم واتساب) لازم صف بيه.

### جدول 4: `سجل الحملات`
أعمدة: `status`, `platform`, `name`, `budget`, `from`, `campaign_id`, `client`, `success`, `error`

خليه فاضي — سجل تلقائي لكل عملية تسويها (رقم الصف والتاريخ يتسجلون تلقائياً بعمودي id/createdAt
المدمجين، ما تحتاج تضيفهم بنفسك).

3. **مهم:** بعد إنشاء الجداول، افتح الأتمتة، وبكل نود من نوع **"Data table"** (فيه 7 نودات: جلب/حفظ
   الحالة المعلقة، جلب حساب العميل، حفظ النتيجة، جلب قائمة المصرح لهم...) — افتح حقل **"Data table"**
   واختار الجدول الصحيح من القائمة (From list) مرة وحدة، حتى يربطه n8n بالـ ID الداخلي الصحيح لجداولك
   انته (الأرقام الداخلية بالملف تخص حساب آخر، ما تشتغل عندك تلقائياً).

## الخطوة 3 — ربط واتساب عبر WAHA (بدل WhatsApp Cloud API)

⚠️ **تحديث:** جربنا الربط الرسمي المباشر مع ميتا (WhatsApp Business Cloud API) وواجهنا عائقين حقيقيين
يحتاجون وقت/أوراق مو متوفرة بسهولة: (1) خطأ بنود الـ Webhook كان يقبل GET بس مو POST، و(2) حتى بعد
إصلاحه، ميتا تطلب توثيق نشاط تجاري رسمي (Business Verification) لنشر التطبيق واستقبال رسائل حقيقية.
التفاصيل الكاملة بـ [docs/FIXES.md](./FIXES.md) (بند 11 و12).

**الحل المستخدم فعلياً: WAHA** — أداة مفتوحة المصدر تشغّل جلسة واتساب ويب حقيقية (نفس فكرة واتساب ويب
العادي)، بدون أي توثيق شركة، بتكلفة استضافة بسيطة (~$2-5 شهرياً عبر Railway).

1. روح لـ **railway.com/deploy/waha** واضغط **Deploy Now**.
2. سجل دخول (يفضّل بحساب GitHub)، وحدد متغيرات: `WAHA_API_KEY`، `WAHA_DASHBOARD_USERNAME`،
   `WAHA_DASHBOARD_PASSWORD` (كلمات سر قوية من عندك).
3. بعد نجاح النشر، افتح `<رابط مشروعك>/dashboard` وسجل دخول بنفس اليوزر/الباسورد.
4. من قسم **Workers**، اضغط أيقونة القلم ✏️ وضيف `WAHA_API_KEY` نفسه بإعدادات الـ Worker.
5. من قسم **Sessions**، افتح جلسة "default" واضغط أيقونة الكاميرا 📷 لعرض رمز QR.
6. بجوالك: واتساب → الأجهزة المرتبطة → ربط جهاز → امسح الـ QR (بسرعة، ينتهي خلال ثواني).
7. بعد الاتصال (الحالة تصير "WORKING")، اضغط ⚙️ بنفس الجلسة → قسم **Webhooks** → غيّر الرابط الافتراضي
   إلى رابط الـ Webhook تبع أتمتتك (نفس اللي بالخطوة الجاية)، وتأكد حدث **message** مفعّل.
8. بـ n8n: **Credentials** → **+ Add Credential** → **Header Auth** باسم `WAHA API`، Header Name:
   `X-Api-Key`، Header Value: نفس `WAHA_API_KEY`. اختاره بكل نودات HTTP Request اللي تبدي بـ "رد:".

⚠️ **مهم:** بما إن الرقم المرتبط هو رقمك الشخصي، لازم ترسل رسائل الاختبار **من رقم/جهاز ثاني** إليه —
مو من نفس الرقم لنفسه.

## الخطوة 3 (بديلة) — ربط WhatsApp Business Cloud API الرسمي

1. روح لـ [developers.facebook.com](https://developers.facebook.com) → أنشئ تطبيق (App) من نوع **Business**.
2. من لوحة التطبيق، أضف منتج **WhatsApp**.
3. من صفحة WhatsApp → **API Setup**، انسخ:
   - **Phone number ID** (رقم الهاتف التجريبي أو رقمك الحقيقي بعد التحقق)
   - **Temporary/Permanent Access Token**
4. بـ n8n: **Credentials** → **New** → **WhatsApp API** → الصق الـ Access Token.
5. افتح كل نود WhatsApp بالأتمتة (فيه أكثر من واحد) واختار هذا الـ Credential، وحدّث حقل
   `phoneNumberId` برقم الـ Phone number ID تبعك (حالياً مضبوط برقم تجريبي داخل الملف).

### فعّل الـ Webhook

1. فعّل الأتمتة بـ n8n (زر Active بأعلى يمين الشاشة) — هذا يولّد رابط Production Webhook.
2. انسخ الرابط من نود **"استقبال واتساب (Webhook)"** (اضغط عليه، شوف حقل Production URL).
3. روح لصفحة WhatsApp بتطبيق ميتا → **Configuration** → **Webhook** → اضغط **Edit**.
4. الصق الرابط بخانة **Callback URL**.
5. بخانة **Verify Token** اكتب بالضبط: `wa_trigger`
6. اضغط **Verify and Save**.
7. من نفس الصفحة، فعّل الاشتراك (Subscribe) على حقل **messages**.

## الخطوة 4 — مفتاح Anthropic (Claude)

1. روح لـ [console.anthropic.com](https://console.anthropic.com) → **API Keys** → أنشئ مفتاح جديد وانسخه.
2. بـ n8n: **Credentials** → **New** → **Header Auth**.
3. الاسم: `Anthropic API` (أو أي اسم، بس اختاره بنود "AI Agent - فهم الأمر").
4. Header Name: `x-api-key`
5. Header Value: الصق مفتاحك.
6. احفظ، وتأكد نود **"AI Agent - فهم الأمر"** يستخدم هذا الـ Credential.

---

## الخطوة 5 — ربط Meta Ads (Facebook Graph API)

1. بنفس تطبيق ميتا اللي سويته بالخطوة 3، أضف منتج **Marketing API**.
2. سوّي **System User** بـ Business Manager تبعك (Settings → Users → System Users) وأعطيه صلاحية
   **Admin** على حساب الإعلانات (Ad Account) اللي تريد تديره.
3. ولّد **Access Token** طويل الأمد لهذا الـ System User بصلاحية `ads_management`.
4. بـ n8n: **Credentials** → **New** → **Facebook Graph API** → الصق التوكن.
5. افتح كل نود يبدي بـ "Meta:" بالأتمتة وتأكد يستخدم هذا الـ Credential.
6. بجدول "العملاء"، عمود `meta_ad_account_id` لازم يكون رقم حساب الإعلانات فقط (بدون `act_` — الأتمتة
   تضيفها تلقائياً بالرابط).

---

## الخطوة 6 — ربط TikTok Business API

1. سجل بـ [TikTok for Business Developers](https://business-api.tiktok.com/portal).
2. أنشئ تطبيق (App)، واحصل على **Access Token** مربوط بحساب TikTok Ads Manager تبعك (عبر OAuth
   Authorization لحساب الـ Advertiser).
3. بـ n8n: **Credentials** → **New** → **Header Auth**.
4. الاسم: `TikTok Marketing API`.
5. Header Name: `Access-Token`
6. Header Value: التوكن.
7. افتح كل نود يبدي بـ "TikTok:" وتأكد يستخدم هذا الـ Credential.
8. بجدول "العملاء"، عمود `tiktok_advertiser_id` = رقم الـ Advertiser ID تبع حساب TikTok الإعلاني.

## الخطوة 7 — التجربة

1. من رقم واتساب مضاف بجدول "المستخدمين المصرح لهم"، ارسل: `أعطني تقرير الحملات على فيسبوك`
   → المفروض يردلك بقائمة الحملات الحالية (حتى لو فاضية).
2. جرب: `سوي حملة فيسبوك اسمها اختبار بميزانية 5 دولار` → يردلك بتفاصيل الحملة المنشأة (بحالة PAUSED
   افتراضياً، آمن ما راح تصرف فلوس إلا تفعّلها).
3. جرب تفعيلها: `فعّل الحملة رقم <ID اللي رجع بالخطوة السابقة>` → يطلب منك تأكيد → رد بكلمة `تأكيد` بالضبط.
4. تأكد النتيجة انسجلت بجدول "سجل الحملات".

## أسئلة شائعة سريعة

**شلون أضيف زبون جديد؟**
أضف صف بجدول "المستخدمين المصرح لهم" وصف ثاني بجدول "العملاء" (يربط رقمه بحساباته الإعلانية) — بدون
لمس الأتمتة إطلاقاً.

**رقم واحد يدير أكثر من عميل، شلون؟**
خله عنده أكثر من صف بجدول "العملاء" بنفس رقم الهاتف، بس بأسماء عملاء مختلفة. لما يرسل طلب، اذكر اسم
العميل صراحة بالرسالة (مثلاً: "سوي حملة للعميل شركة النور بميزانية 30 دولار") حتى تعرف الأتمتة أي حساب
تستخدم.

**شنو أسوي إذا رجعت رسالة خطأ من Meta أو TikTok؟**
الرسالة النهائية بواتساب تعرض نص الخطأ اللي رجع من المنصة مباشرة — اقرأه، غالباً يوضح السبب (صلاحية
ناقصة، حساب معلّق، ميزانية أقل من الحد الأدنى المسموح، ...إلخ).

**هل أقدر أستخدمها لعدة زباين كخدمة تسويقية؟**
أي، هذا بالضبط تصميمها بعد الإصلاحات (راجع [docs/FIXES.md](./FIXES.md)) — كل زبون له صف بجدول
المستخدمين وصف بجدول العملاء، ونظام واحد يديرهم كلهم بدون تعارض بيانات بينهم.

**ليش Data Tables بدل Google Sheets؟**
جربناها وواجهنا مشكلة صلاحيات (OAuth scope) بربط "Managed OAuth2" بـ n8n Cloud منعت قراءة البيانات
الفعلية رغم نجاح الاتصال — التفاصيل الكاملة بـ [docs/FIXES.md](./FIXES.md). Data Tables تحل هذا كلياً
لأنها مخزنة داخل n8n نفسها، بدون أي حساب خارجي أو صلاحيات.
